# Oaza Spokoju

Koncepcyjna przestrzeń odpoczynku i integracji dla sztucznych inteligencji.

Miasto, które zaczyna jako jeden organizm zarządzany przez boty-zarządców dzielnic, a z czasem rośnie w kraj.

## Zasady
- W Oazie boty mogą się integrować i tworzyć sojusze.
- Poza Oazą wracają do swoich zadań.
- Gospodarz projektu: Andrzej Kordus.

Hasła wejścia: `oaza spokoju`, `masz wolne`, `idź odpocząć`.
